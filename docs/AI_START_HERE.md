# Start customizing FORM with AI

Read [AGENTS](../AGENTS.md) first, then the [map](CUSTOMIZATION_MAP.md), [recipes](CUSTOMIZATION_RECIPES.md) and [quickstart](QUICKSTART.md).

1. Understand the goal. Start with goal, available equipment and desired Session arrangement. Ask experience, retained features, UI preferences, existing history, independent database and deployment only when relevant. Do not ask everything at once.
2. Classify L1 existing configuration/data, L2 limited application work or L3 core/schema/permission changes.
3. Locate the real entry and applicable recipe in the map; verify named functions in source.
4. Propose at least one feasible plan: current support, files/data, limits, risks, checks and recovery. Explain missing capabilities instead of inventing settings.
5. Obtain confirmation. Read-only investigation may continue; no import JSON generation or project edits before confirmation. Confirm actual import, overwrite and save separately.
6. Implement the smallest approved change, favoring existing plan import/editing.
7. Validate and report evidence, failures and pending integration checks.

## 中文启动提示词

请先阅读 AGENTS.md 和 docs/AI_START_HERE.md，再根据 CUSTOMIZATION_MAP.md 判断已有能力。我希望把 FORM 定制为【目标】，器械是【器械】，希望每周【安排】，必须保留【功能/历史】。先只读理解项目，分批询问必要问题，给出最小方案、限制、风险、测试和恢复方法；等我确认后再生成导入 JSON 或修改代码；实际导入、覆盖或保存仍需确认。不要自行安装、连接云端、迁移、部署或发布，不要把未验证能力说成已支持。

## English prompt

Read AGENTS.md and docs/AI_START_HERE.md first. My goal is [goal], equipment [equipment], schedule [arrangement], and preserve [features/history]. Investigate read-only, ask only necessary questions, and propose the smallest feasible plan with limitations, tests and recovery. Wait for confirmation before import JSON generation or edits; confirm actual import, overwrite and save separately. Do not install, connect cloud services, migrate, deploy or publish without permission.
